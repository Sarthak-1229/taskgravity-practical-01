# Antigravity Prompt: Practical 01

## 🎨 Design & Code Rules
1. **Minimalist UI**: Use a flat, minimal design system. Avoid generic gradients, heavy shadows, or layout tropes that make the site look 'AI-generated'. Keep it sleek, professional, and content-focused.
2. **Efficiency**: Deliver maximum output with minimal code. Keep components DRY, avoid redundant CSS, and use clean logic.
3. **Topic Theme**: Build a 'Task Management System' (TaskGravity). Keep this theme consistent across the practicals as they scale from static HTML to full-stack MongoDB.

## 📝 Assignment Requirements
Design and develop a single-page web application. Use HTML5 for structure, CSS3 for custom styling, and Bootstrap for responsive grid layouts. The page must be responsive across desktop, tablet, and mobile. Include header, navigation, main/banner section, content, and footer. Use at least 3 distinct Bootstrap components.
